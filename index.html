📖 操作說明

📱 手機觸控操作

  • 左下十字鍵：長按持續控制 Tommy 四方向移動，放開即停。
  • 右下 A 鍵：靠近家具或人物進行互動、確認或推進對話。
  • 右下 B 鍵：關閉當前對話或返回。
  • 右上 ⚙️ 圖示：隨時開啟音效、音樂與功能選單。

💻 電腦鍵盤操作

  • 移動：WASD 或方向鍵 ↑↓←→
  • 確認 / 互動 (A鍵)：Space / Enter (含數字鍵 Enter) / Z
  • 返回 / 取消 (B鍵)：Esc / X

✨ 關於 Tommy (ABOUT)

🎮 設計初衷

「與其看完一份制式的自我介紹，不如花幾分鐘，走進我的生活。」

這款小遊戲受到 GBA 時代 16-bit 經典 RPG 啟發，希望能讓有緣的妳，透過輕鬆、溫暖而自在的互動，認識一個真實、熱愛生活與閱讀的男生。

💡 探索提示

走近房間內的茶几、書架、工作筆電、日職球帽、微型投影機等物品，按下 A 鍵即可解鎖 Tommy 的生活故事；走到下方門口地毯更能一起出發去咖啡廳、河濱公園與書店喔！
